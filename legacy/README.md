# legacy

这里放历史版本，给仍在使用旧版 Comfyui-Anima-Wardrobe 的环境使用。

| 目录 | 插件版本 | 适用的 AnimaWardrobe | 说明 |
| --- | --- | --- | --- |
| `v1.0.0/` | 1.0.0 | **V5** | 首个可分发版本。没有「干爽」「双女」「场景锁」；角色库路径写死 V5 安装目录 |

安装方式与根目录相同：

```bash
dsh plugin add link:<legacy/v1.0.0 的绝对路径>
```

装完**完全退出 DSH 再重开**。

注意：同一时间只能安装一个版本。要换回新版，先在插件管理器里移除旧版。
