# 历史版本

这些目录里的代码**仅供追溯**，不要直接安装 —— 每个版本都对应完整的插件包，同一时间只能装一个。

| 目录 | 版本 | 适用节点 | 说明 |
|---|---|---|---|
| （仓库根） | 1.3.3 | V5 / V6 | 当前版本，含内嵌随机面板与「当前套用」 |
| `v1.1.1/` | 1.1.1 | V5 / V6 | 含 V6 三个新输入（干爽 / 双女 / 场景锁），无随机面板内嵌 |
| `v1.0.0/` | 1.0.0 | **仅 V5** | 最早版本，没有 V6 专属能力 |

## 升级方式

把新版本的文件覆盖到插件目录，或直接用 `release/` 里的 tgz 重装，然后完全退出 DSH 再重开。

## 回滚

把 `legacy/v1.1.1/` 或 `legacy/v1.0.0/` 里的 8 个文件覆盖回插件目录，重装该版本即可。
